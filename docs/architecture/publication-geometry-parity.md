# Publication geometry parity

The regression fixture is generated by the shared `ControlledPublishingBookRenderer`; it is not hand-written reader markup. It contains a data-URI logo and figure, so the run has no network dependency.

Generate and validate:

```sh
php scripts/build_publication_geometry_fixture.php
php tests/publication_geometry_parity_contract_check.php
node --check scripts/qa_publication_geometry_parity.js
node scripts/qa_publication_geometry_parity.js
```

The browser test targets Playwright WebKit from `scripts/garmin/node_modules/playwright`. If the browser executable is absent, install it with:

```sh
cd scripts/garmin && npx playwright install webkit
```

Chromium is available only as an explicitly reported diagnostic fallback:

```sh
node scripts/qa_publication_geometry_parity.js --browser=chromium
```

The checked-in policy defines DOM geometry, computed-style, and pixel tolerances. Screenshots are diagnostic artifacts; no opaque image baseline is checked in because the stronger assertion compares renderer and iOS output in the same browser run.

To refresh the optional computed renderer baseline after an intentional visual change:

```sh
node scripts/qa_publication_geometry_parity.js --update
```

Review the policy diff and both generated screenshots before accepting an update. Fixture updates must be made by rerunning the PHP builder.
